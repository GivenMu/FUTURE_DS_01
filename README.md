# Business Sales Performance Analytics

## Project Overview
This project analyzes business sales data using Microsoft Excel PivotTables and PivotCharts.

## Objectives
- Analyze sales trends over time
- Identify top-performing categories
- Analyze profit by category
- Discover top-selling products

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts

## Key Insights
- Technology generated the highest sales and profit
- Sales increased significantly over the years
- Certain products consistently outperformed others
