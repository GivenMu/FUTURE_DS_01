# Customer Retention & Churn Analysis TASK 2

## Overview
This project focuses on analyzing customer churn and retention patterns using Excel.

The objective was to identify:
- Customer churn trends
- High-risk customer groups
- Retention opportunities
- Business recommendations

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts

## Key Insights
- Month-to-month contracts showed the highest churn.
- Fiber optic customers had higher churn compared to other internet services.
- Customers using electronic checks showed increased churn rates.

## Recommendations
- Encourage long-term contracts.
- Improve fiber optic customer experience.
- Promote automatic payment methods to reduce churn.
